# Lakaze Part 3 setup and testing

## Implemented in this code
- JS-rendered menu using `js/menu-data.json` (with file:// fallback), search, sorting and live pricing.
- Food/catering estimate calculator, quantities, and enquiry summary.
- Gallery image lightbox, keyboard access, reveal animations and reduced-motion support.
- South African mobile validation, required fields, error messages, AJAX submission support.
- OpenStreetMap area embed; this is not a verified Lakaze premises pin.
- Existing SEO titles, descriptions, semantic headings, images and navigation retained.
